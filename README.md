# 夜幕审判

一款玩家与 AI 共同参与的浏览器狼人杀游戏。支持 6 至 15 人动态牌组、身份揭示、昼夜轮替、神职技能、文字发言、AI 推理、放逐投票和胜负结算。

## 当前版本亮点

* 狼人、预言家、女巫、猎人、守卫、白痴、骑士和村民拥有不同的角色策略提示词。

* AI 会结合公开历史理解玩家发言，主动赞同、反驳、追问其他玩家，并保持角色私密信息隔离。

* 每轮发言顺序随机，玩家不固定第一个发言。

* 发言严格按席位顺序推进，轮到 AI 时自动回复，轮到玩家时才开放输入框。

* AI 按顺序逐字输出，发言气泡显示在当前角色头像上方。

* 夜间严格按照狼人、守卫、预言家、女巫、天亮结算的顺序逐步行动。

* 女巫解药只在存在未被守卫保护的狼人袭击目标时可用，并固定救治该目标。

* 身份卡只向玩家本人展示，牌桌头像全部使用与身份无关的公开人物图像。

* 玩家统一使用 `1号`、`2号`、`3号` 等序号名称。

* AI 会先分析昨夜死亡或平安夜，再针对前面玩家的具体发言给出证据链；神职可以公开真实信息，狼人可以假跳神职，村民也可以策略性诈身份。

* 支持创建联机房间、邀请链接加入、真人准备、AI 自动准备、房主补齐或移除 AI，以及全员准备后的同步开局。

* 联机对局由 Render 服务端统一保存和推进；真人席位不会再被其他客户端当成 AI，每名玩家看到的是同一局游戏。

* 联机夜间每个角色阶段统一倒计时 10 秒，超时后服务端自动推进，不需要其他玩家点击按钮。

* 白天每名真人玩家有 60 秒发言时间，超时后服务端自动过麦并同步到所有客户端。

* 狼人夜间可以看到狼队友，并通过仅狼人可见的私密频道讨论袭击目标。

* AI 狼人会理解“杀几号”等明确指令，在私密频道回复并跟随真人狼队友投刀；狼刀支持自刀、多数票和最高票平票随机。

* 联机席位带有短时断线恢复令牌，页面刷新后可以回到原身份和原对局。

* WebSocket 意外中断后会自动重连；离线玩家的发言会立即跳过，投票不会阻塞其他在线玩家。

* 放逐投票统一为 60 秒倒计时；终局公开所有身份与整局秘密行动记录。

* 新增原创夜幕村庄背景，以及可关闭的昼夜环境音和阶段切换音效。

## 启动

```bash
npm install
npm run server
```

另开一个终端启动前端：

```bash
npm run dev
```

开发环境默认通过 Vite 的同源 `/ws` 代理连接 `ws://localhost:3001`，无需额外配置。

生产构建：

```bash
npm run build
```

GitHub Pages 前端与 Render 房间服务的完整部署步骤见 [DEPLOYMENT.md](./DEPLOYMENT.md)。

## DeepSeek 设置

点击页面右上角的“本地 AI”打开设置：

* 输入 API Key。

* API Base URL 默认是 `https://api.deepseek.com`。

* 模型默认是 `deepseek-v4-flash`，可按账号实际可用模型修改。

* 打开“启用 DeepSeek”并保存。

* 不配置密钥时，游戏自动使用免费的本地策略 AI。

每名 AI 在轮到自己时单独请求 DeepSeek。请求只包含该角色自己的身份、性格、私密信息和当时已经公开的对话，因此能够形成真正独立的角色认知，并自然回应前面玩家。该模式每轮最多调用“存活 AI 数量”次 API，请在意费用时降低游戏人数或关闭远程 AI。

每次回复最多使用 `360 tokens`，请求失败或超时后自动切换到本地 AI。逐字输出效果由前端播放，不会产生额外 API 请求。

当前版本把 API Key 保存在浏览器 `localStorage` 中，适合本地试玩。公开部署时应增加服务端代理，避免在浏览器中暴露长期密钥。

## 代码结构

* `src/game.ts`：身份、人数配置、牌组生成、夜间结算、投票和胜负规则。

* `src/ai.ts`：DeepSeek 独立角色请求、有限信息隔离和本地 AI 降级。

* `src/multiplayer.ts`：房间 WebSocket 客户端协议与邀请链接。

* `server/index.mjs`：Render 房间服务、准备状态、消息路由和计时调度。

* `server/game.mjs`：服务端权威牌局、夜间结算、发言、投票和私密视图。

* `src/App.tsx`：页面流程、房间大厅、对局交互和设置界面。

* `src/App.css`：哥特式视觉系统、身份特效和响应式布局。

* `public/role-atlas.jpg`：角色视觉生成资源。

* `public/player-avatar-atlas.jpg`：与身份无关的公开玩家头像图集。

## 联机边界

当前版本的身份、夜间行动、发言顺序、倒计时、投票和胜负结算均由房间服务端统一推进，并按席位过滤身份、查验与狼聊等私密信息。浏览器刷新可凭当前标签页的会话令牌恢复原席位；房间仍保存在 Render 单实例内存中，服务重启会丢失房间。正式运营时建议接入 Redis 持久化房间和会话。
